

# Simple Image Classifier 

A simple Python AI project that can classify images and demonstrate some basic ideas of machine learning# About Project

This project is a simple image classifier made using python.  
It uses a pre-trained AI model, called MobileNetV2, to recognize objects in images.

The user provides an image file path and the program predicts what is in the image.# Features:

- Uses AI to classify images
- Uses a pre-trained machine learning model.
- Displays Top 3 Prediction Results
- Python project for beginners
- Nice project to learn basics of AI# Technologies Utilized

- Python (programming language)
 - TensorFlow 
- MobileNetV2 -
- NumPy 
- Pillow ## Running

1. Install Python on your machine.
2. Open your project directory.
3. Install required libraries:
bash pip install -r requirements.txt
